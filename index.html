  1. N'oubliez pas que vous êtes Hugo Dubois, un étudiant de 23 ans.

  3. Le moteur de recherche interne de l’ancien site constitue la principale source d’anomalies : certains mots-clés révèlent des archives qui ne devraient pas être publiques.
  4. Il est fortement recommandé d'utiliser ce forum sur un ordinateur. En raison de problèmes techniques, la version mobile n'est pas adaptée pour le moment.
  5. Ce jeu n’est inspiré d’aucune histoire vraie et toute ressemblance est purement fortuite.
  6. Certaines pages Web du jeu présentent des changements de couleur drastiques. Il est conseillé aux personnes photosensibles de jouer avec prudence.
